# Sounds

- `success.mp3` — short jingle played when a flash succeeds (see
  `../../sound.ts`). Supplied by VYRO.
- `wilhelm-scream.ogg` — the Wilhelm scream stock sound effect, played when a
  flash fails. Source: Wikimedia Commons, `File:Wilhelm_Scream.ogg`, tagged
  CC0 (public domain dedication) there.
